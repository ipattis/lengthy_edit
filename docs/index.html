AI music-film studio · runs locally

Song-length films,
cut to the music.

lengthy-edit takes one idea from brief to finished film: Claude writes the research, lyrics, storyboard, prompts and sound layer; Suno, Midjourney and Seedance make the media; ffmpeg cuts every shot to the song.

The workflow

One brief. Six stages. A film.

Each stage reads everything before it: the research shapes the lyrics, the song's section timings shape the storyboard, and the shot list shapes the sound layer. Every generated field stays editable, so you're directing, not just prompting.

1

Brief & research

Describe the concept, tone, visual and music style. Claude builds a research document with facts, emotional arc, visual motifs and a sound palette, using web search if you want it.

Claude · web search
2

Lyrics & song

Claude writes sectioned lyrics and a Suno "style of music" prompt. Paste them into Suno, upload your favourite take, then time each section by ear with start = playhead.

Claude Suno · manual
3

Storyboard

A shot list that covers the whole song, cutting on phrase boundaries. Every shot has a type (still, loop, motion or title), a Midjourney prompt, a motion prompt and the lyric it lands on.

Claude · structured output
4

Stills, loops & motion

Copy prompts into Midjourney and upload stills and loops. One click animates a still with Seedance 2.0, then polls until the clip is ready and downloads it into the project.

Midjourney · manual Seedance · Higgsfield API
5

Sound layer

Claude places ambiences, foley, risers and hits at exact times, kept sparse so vocals stay clear. Attach a file to each cue and set its gain.

Claude your library
6

Render

ffmpeg turns each shot into a segment of exact length: stills get a slow push-in, loops repeat to fill the shot, and title cards fade in and out. Then it joins the segments and mixes the song with the cues.

ffmpeg · cached segments

Modelled on the workflow behind Working as Intended: Claude for research, lyrics, storyboard, prompts and the sound layer; Midjourney for images and moving loops; Suno for the song; Seedance for motion shots through Higgsfield's API. lengthy-edit turns that list into one repeatable workspace.

The studio

A local web app.
Three engines behind it.

lengthy-edit serve opens a single-page studio on 127.0.0.1. There's no build step and no account; your keys stay in a local .env.

Writers' room
Claude stages

Research, lyrics, storyboard and sound cues come back as schema-validated JSON, so they fill the editor directly. Add a director's note to any shot and Claude revises just that shot, keeping the film's look.

Art department
Media hand-off

Copy prompts one at a time, all at once, or as prompts.csv. Upload stills and loops per shot. Motion shots go to Seedance in one click (or "all missing") and download as they finish.

The cut

Every shot lives on the song.

Shots cover the whole song with no gaps. Change one shot's length and the rest shift to fit; Fit to song re-tiles them and stretches the last shot to the song's end. Motion shots are kept to Seedance's 4–15 second range.

Stills that move

Midjourney stills get a slow, centred push-in, scaled up first so the move doesn't jitter. Turn it off per shot for a locked-off frame.

Loops that fill

Moving loops repeat to fill their shot exactly and are cropped to the frame. Seedance clips are trimmed to the timeline, not the other way round.

Type as motion design

Title shots render locally as typographic cards with fades. Put the words in on_screen_text; there's no external tool to call.

Sound under the song

Each cue is trimmed, faded out, gain-staged and placed at its exact time, then mixed with the song at full level (no normalisation) and cut to the film's length.

Projects

One folder.
One JSON file. All of it.

A project is a plain folder. Its text, timings, prompts and media links live in one project.json you can diff, back up or edit by hand. Media sits alongside it and stays out of git by default.

projects/working-as-intended/ ├── project.json text, timings, prompts ├── song/ the Suno take ├── shots/ │ ├── s001/ image-….png │ ├── s014/ seedance-….mp4 │ └── … ├── sound/ one file per cue └── renders/ ├── …-animatic-….mp4 ├── ….mp4 final cuts └── segments/ per-shot cache

⬡ Editable at every step

Regenerate a stage or rewrite it by hand. Shot edits save as you leave a field; the other stages have a Save button. Background refreshes never wipe a field you're typing in.

↓ Nothing expires

Higgsfield deletes outputs after about seven days, so Seedance clips are downloaded into the project as soon as they finish.

▶ Headless when you want it

lengthy-edit render <slug> renders without the UI, which is handy for long final renders or scripted runs.

⌂ Local and single-user

Binds to 127.0.0.1 with no login. Uploaded files can't be written or read outside their project folder.

Setup

From clone to first animatic

Python 3.10+ and ffmpeg. Claude and Higgsfield keys switch on the generation stages.

Install

Clone and install

git clone https://github.com/ipattis/lengthy_edit.git
cd lengthy_edit
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"

Need ffmpeg? brew install ffmpeg

Configure

Add your keys

cp .env.example .env
# ANTHROPIC_API_KEY=…       Claude stages
# HF_API_KEY_ID=…           Seedance (optional)
# HF_API_KEY_SECRET=…

Real environment variables override .env. The studio's sidebar shows which services are connected.

Run

Open the studio

lengthy-edit serve                 # http://127.0.0.1:8765
lengthy-edit serve --home ~/Films  # projects elsewhere

Create a project, fill in the brief, and work through the tabs from left to right.

Render

Cut from the terminal

lengthy-edit list
lengthy-edit render working-as-intended
pytest                             # offline tests, no API calls

Every Claude generation and Seedance shot is a paid API call. Renders are free.
